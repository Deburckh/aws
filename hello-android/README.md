# Hello Android (Kotlin)

A minimal Android app with one screen, built with Kotlin, AppCompat, and ViewBinding.

## Requirements
- Android Studio Ladybug or newer
- Android SDK Platform 34 installed
- JDK 17 (bundled with Android Studio is fine)

## How to open
1. Open Android Studio
2. File → Open… → select the folder `/workspace/hello-android`
3. Let Gradle sync finish

## Run
- Choose an emulator or device and click Run

The app shows a text and a button; tapping the button updates the text.
